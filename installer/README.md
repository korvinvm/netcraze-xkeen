# Xray на Keenetic: весь путь от нуля до рабочего туннеля

Этот документ — полная инструкция. От «роутер только из коробки» до «интернет идёт
через заграницу, сам переключается, когда сервер умирает».

Всё, что делает программа, описано честно: что она трогает, что не трогает и как откатить.

---

## Что получится

1. Подписка (Liberty или обычная) превращается в рабочий конфиг Xray.
2. Основная сеть ходит через туннель только по 80/443, российские сайты — напрямую.
3. Гостевая сеть ходит **строго** через туннель, IPv6 и QUIC закрыты, чтобы адрес не утёк.
4. Раз в 30 минут подписка обновляется; раз в 5 минут проверяется, жив ли туннель.
5. Если сервер умер — программа сама берёт другой из подписки.
6. Если не поднялся ни один — оставляет прежний рабочий конфиг и повторяет через 10 минут.

---

## Что нужно заранее

| Что | Зачем | Обязательно |
|---|---|---|
| Роутер Keenetic с USB | на нём всё живёт | да |
| USB-флешка (8 ГБ хватит) | туда ставятся пакеты | да |
| Подписка (ссылка) | откуда берутся серверы | да |
| Компьютер с SSH-клиентом | чтобы закинуть файл и запустить | да |

Моя конфигурация для примера: **Netcraze NC-1812**, процессор `aarch64` (это `arm64`),
прошивка KeeneticOS 5.x. Для других моделей отличается только файл бинарника —
какой брать, написано в шаге 3.

---

## Шаг 1. Проверить, есть ли Entware

Entware — это «папка `/opt` с пакетами». Без неё ставить некуда.

Подключись к роутеру по SSH (шаг 2, если ещё не умеешь) и выполни:

```sh
ls /opt/bin | head
```

- **Есть список файлов** → Entware уже стоит, переходи к шагу 3.
- **`No such file or directory`** → Entware не установлен, ставь по шагу 1а.

### Шаг 1а. Установка Entware (только если /opt отсутствует)

Официальный путь: Keenetic → веб-интерфейс → «Управление» → «Общие настройки» →
«Изменить набор компонентов» → добавить **«Менеджер пакетов opkg»** и **«Сервер SSH»**.
После перезагрузки в CLI появляется `opkg`, а на флешку ставится Entware
(актуальная инструкция — на сайте поддержки Keenetic, раздел Entware;
команды меняются от версии прошивки к версии, поэтому не копируй их из старых статей).

Признак успеха ровно один:

```sh
ls /opt/bin | head          # должен показать файлы
/opt/bin/opkg --version     # должен ответить версией
```

Дальше не идём, пока эти две команды не работают.

---

## Шаг 2. SSH-доступ

В Keenetic: «Управление» → «Общие настройки» → набор компонентов → включить **«Сервер SSH»**.
После этого:

```sh
ssh admin@192.168.1.1
```

Пароль — **твой** пароль администратора роутера. Никаких «стандартных» паролей здесь нет:
если пароль не подходит, значит он другой, и его надо вводить свой.

Проверь, что ты там, где нужно:

```sh
uname -m        # aarch64 = arm64, mips = mipsle, armv7l = armv7
```

Запомни вывод — от него зависит, какой бинарник брать.

## Шаг 3. Закинуть программу на роутер

Возьми файл под свою архитектуру из папки `dist/` (или из релизов):

| `uname -m` | Файл |
|---|---|
| `aarch64` | `keen-xray-arm64` |
| `armv7l` | `keen-xray-armv7` |
| `mips` | `keen-xray-mipsle` |

Копируем с компьютера:

```sh
scp keen-xray-arm64 admin@192.168.1.1:/opt/bin/keen-xray
ssh admin@192.168.1.1 "chmod +x /opt/bin/keen-xray"
```

Если `scp` нет, а на роутере есть интернет — можно скачать прямо там:

```sh
cd /opt/bin && wget -O keen-xray <ссылка на файл> && chmod +x keen-xray
```

## Шаг 4. Одна команда — и всё работает

```sh
/opt/bin/keen-xray install --sub 'https://твоя-подписка/токен'
```

Что произойдёт по шагам (всё пишется в `/opt/var/log/keen-xray.log`):

1. **Проверит Xray.** Если `/opt/sbin/xray` нет — скачает официальный бинарник
   с GitHub под архитектуру роутера и создаст автозапуск `/opt/etc/init.d/S24xray`.
   Если Xray уже стоит (например, от XKeen) — **не трогает**.
2. **Скачает подписку.** Сначала напрямую; если не вышло — через уже поднятый туннель.
3. **Разберёт её.** JSON (Liberty, v2rayN) или base64-список `vless://` / `vmess://` / `trojan://` —
   определяет автоматически, указывать тип не нужно.
4. **Соберёт конфиг.** Серверы + правила: DNS через Xray, приватные сети напрямую,
   российские сайты напрямую (флаг `--route ru-direct`, по умолчанию), остальное — через туннель.
5. **Сохранит бэкап.** Прежние конфиги копируются в `/opt/var/keen-xray/backup-ДАТА/`.
6. **Проверит конфиг** через `xray run -test` — сломанный в работу не попадёт.
7. **Поднимет туннель** и проверит внешний IP через SOCKS. Если сервер не ответил —
   возьмёт следующий из подписки.

Полезные варианты:

```sh
# всё через туннель, без исключений для российских сайтов
/opt/bin/keen-xray install --sub 'URL' --route all

# только собрать конфиг, не перезапуская Xray (посмотреть глазами)
/opt/bin/keen-xray install --sub 'URL' --skip-restart

# проверить подписку на компьютере, вообще не трогая роутер
keen-xray gen --sub sub.txt --out out
```

## Шаг 5. Проверка

```sh
/opt/bin/keen-xray status
```

Ожидаемо:

```
активный сервер: proxy-1-node-example-org
внешний IP через туннель: 203.0.113.77
подписка: https://sub.example…
```

Если внешний IP отличается от твоего домашнего — туннель работает.

Проверка «глазами» с компьютера в этой же сети:

```sh
curl -x socks5h://192.168.1.1:1082 https://api.ipify.org
```

Должен вернуться тот же заграничный адрес.

## Шаг 6. Автозапуск и сторож

Сторож — это то, что делает систему самоподдерживающейся:

```sh
/opt/bin/keen-xray guard --every 5m --sync-every 30m
```

- каждые **5 минут** — проверка туннеля;
- каждые **30 минут** — перечитывание подписки (появились новые серверы — подхватит);
- туннель упал → перебор серверов и подъём первого живого;
- ничего не поднялось → откат на прежний конфиг, повтор через 10 минут.

Чтобы работало после перезагрузки роутера, создай `/opt/etc/init.d/S99keen-xray`:

```sh
#!/bin/sh
PID=/opt/var/keen-xray/guard.pid
case "$1" in
  start) nohup /opt/bin/keen-xray guard >/dev/null 2>&1 & echo $! > $PID ;;
  stop)  [ -f $PID ] && kill "$(cat $PID)" 2>/dev/null; rm -f $PID ;;
  restart) $0 stop; sleep 1; $0 start ;;
  status) [ -f $PID ] && kill -0 "$(cat $PID)" 2>/dev/null && echo работает || echo "не работает" ;;
esac
```

```sh
chmod +x /opt/etc/init.d/S99keen-xray
/opt/etc/init.d/S99keen-xray start
```

## Шаг 7. Правила для сетей

Нужны, чтобы трафик действительно шёл в туннель, а не мимо.

```sh
/opt/bin/keen-xray firewall --lan 192.168.2.0/24 --guest 10.1.30.0/24
```

- `--lan` — адрес твоей основной сети (посмотри в веб-интерфейсе роутера);
- `--guest` — адрес гостевой сети (её надо создать в интерфейсе Keenetic:
  «Мои сети и Wi-Fi» → «Гостевая сеть»; адрес Keenetic выдаёт сам, обычно `10.1.30.0/24`).

Что ставят правила:

| Сеть | Что происходит |
|---|---|
| основная | DNS → Xray, TCP 80/443 → туннель, остальное напрямую |
| гостевая | **весь** TCP → туннель, DNS → Xray, IPv6 и QUIC закрыты |

Правила не сохраняются в конфиг роутера — их надо ставить при старте. Добавь в тот же
`S99keen-xray` строку перед запуском сторожа:

```sh
/opt/bin/keen-xray firewall --lan 192.168.2.0/24 --guest 10.1.30.0/24
```

## Что уже стоит у тебя (если настраивал по этой же инструкции)

Отметь галочки — и не делай лишнего:

| Компонент | Проверка | Что делать |
|---|---|---|
| Entware | `ls /opt/bin` | ✅ уже стоит — **шаг 1 пропускаем** |
| Xray | `ls /opt/sbin/xray` | ✅ уже стоит — программа его не тронет |
| XKeen | `ls /opt/sbin/xkeen` | ✅ стоит — **не нужен, но и не мешает** |
| Старый сторож | `ls /opt/etc/init.d/S99xrayguard` | ⚠️ **удалить**: его заменяет `keen-xray guard` |
| Старые скрипты | `/opt/etc/xray/sub-sync.sh`, `health.sh` | ⚠️ можно удалить, дублируют бинарник |
| Конфиги Xray | `/opt/etc/xray/configs` | программа дополнит, старое сохранит в бэкап |

Удалить старое (по желанию, ничего не сломает):

```sh
rm -f /opt/etc/init.d/S99xrayguard
rm -f /opt/etc/xray/sub-sync.sh /opt/etc/xray/health.sh
```

## Две подписки — обе работают

| Тип | Как выглядит в браузере | Что делает программа |
|---|---|---|
| **Liberty / v2rayN** | JSON с `outbounds` | берёт серверы как есть, сохраняет теги |
| **Обычная** | длинная base64-строка, внутри `vless://…` | раскодирует и собирает серверы |

Поддерживается: **VLESS** (включая REALITY и `xtls-rprx-vision`), **VMess**, **Trojan**;
транспорт **tcp / ws / grpc**; шифрование **TLS**, **REALITY**, без шифрования.

Если в подписке смешаны протоколы — тоже нормально, каждый сервер разбирается отдельно.

## Если что-то пошло не так

**Ничего не поднялось.** Смотри журнал:

```sh
tail -40 /opt/var/log/keen-xray.log
```

Там по шагам: скачалась ли подписка, сколько серверов нашлось, какие не ответили.

**Хочу вернуть как было.**

```sh
ls /opt/var/keen-xray/backup-*/
cp /opt/var/keen-xray/backup-20261105-120000/*.json /opt/etc/xray/configs/
/opt/etc/init.d/S24xray restart
```

**Интернет пропал совсем.** Останови сторожа, проверь Xray руками:

```sh
kill "$(cat /opt/var/keen-xray/guard.pid)" 2>/dev/null
/opt/etc/init.d/S24xray restart
/opt/etc/init.d/S24xray status
```

**Подписка не скачивается.** Программа уже пробует два пути (напрямую и через туннель).
Если оба не работают — проверь ссылку в браузере на компьютере и не истекла ли подписка.

**Роутер не пускает в интернет после правил firewall.** Перезагрузка роутера сбрасывает
правила (они не сохраняются). Если ставил их вручную и что-то не так — просто перезагрузи.

---

## Как всё удалить

```sh
/opt/etc/init.d/S99keen-xray stop 2>/dev/null
rm -f /opt/etc/init.d/S99keen-xray /opt/bin/keen-xray
rm -rf /opt/var/keen-xray /opt/etc/xray
# если ставили Xray нашей программой — убрать и его
rm -f /opt/sbin/xray /opt/etc/init.d/S24xray
```

Entware остаётся — он ставился не нами.

## Как это устроено внутри (для тех, кому интересно)

```
подписка → разбор (JSON / base64 / ссылки) → список outbound'ов
         → правила маршрутизации (dns, приватные сети, ru-direct, гостевая сеть)
         → проверка xray run -test
         → бэкап → атомарная запись → перезапуск → проверка внешнего IP через SOCKS
```

Порты:

| Порт | Назначение |
|---|---|
| 61219 | перенаправление основной сети (80/443) |
| 61220 | гостевая сеть (весь трафик) |
| 1082 | SOCKS — для проверок и отладки |
| 5354 | DNS через туннель |

```sh
go build -ldflags "-s -w" -o keen-xray .

GOOS=linux GOARCH=arm64  CGO_ENABLED=0 go build -ldflags "-s -w" -o keen-xray-arm64 .
GOOS=linux GOARCH=arm    GOARM=7 CGO_ENABLED=0 go build -ldflags "-s -w" -o keen-xray-armv7 .
GOOS=linux GOARCH=mipsle GOMIPS=softfloat CGO_ENABLED=0 go build -ldflags "-s -w" -o keen-xray-mipsle .
```

Проверить разбор подписки, не имея роутера:

```sh
./keen-xray gen --sub test-sub.txt --out out && cat out/04_outbounds.json
```
